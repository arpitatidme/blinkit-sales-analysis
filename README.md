# 🛒 Blinkit Sales Analysis

### End-to-End Data Analytics Project | Python • MySQL • SQL • Power BI

> An end-to-end sales analytics project designed to transform raw Blinkit sales data into meaningful business insights through data cleaning, exploratory analysis, SQL analysis, and interactive Power BI reporting.

---

## 📌 Project Overview

This project analyzes Blinkit's sales data to understand how sales performance varies across:

- Product categories
- Item characteristics
- Outlet types
- Outlet sizes
- Outlet location tiers
- Fat content
- Product ratings
- Item visibility

The project follows a complete analytics workflow:

**Raw Data → Python → MySQL/SQL → Power BI → Business Insights**

The goal was not only to calculate sales metrics, but also to identify patterns that could support better business decisions.

---

## 🎯 Business Problem

A retail business generates large amounts of sales data, but raw data alone does not provide clear answers to important business questions.

This project focuses on questions such as:

- Which product categories generate the most sales?
- Which outlet types contribute the most revenue?
- Which location tier performs best?
- Does outlet size affect sales?
- How do Low Fat and Regular products compare?
- Is product rating strongly associated with sales?
- Does item visibility have a meaningful relationship with sales?
- Which outlet segments should receive more attention?

---

## 🎯 Project Objectives

The main objectives of this project were to:

1. Clean and prepare the raw sales dataset.
2. Perform exploratory data analysis using Python.
3. Analyze sales performance using MySQL and SQL.
4. Use advanced SQL techniques such as CTEs and window functions.
5. Build an interactive Power BI dashboard.
6. Identify important business patterns.
7. Convert analytical findings into business recommendations.

---

# 📊 Dataset

The dataset contains **8,523 sales records** and includes information related to products and outlets.

### Major fields include:

| Category | Fields |
|---|---|
| Product | Item Identifier, Item Type |
| Product Attributes | Fat Content, Visibility, Weight |
| Sales | Sales |
| Outlet | Outlet Identifier, Outlet Type |
| Location | Outlet Location Tier |
| Outlet Attributes | Outlet Size, Establishment Year |
| Customer/Product Feedback | Rating |
